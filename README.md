# Streamlit app: Drug Clinical Trial Survival Analysis

## Folder
streamlit_app/
  app.py
  requirements.txt
  data/
    km_curves.csv            (from your notebook, Step 13C)
    cox_hazard_ratios.csv    (from your notebook, Step 13D)

## Run on your laptop
1. pip install -r requirements.txt
2. streamlit run app.py

## Put it online (free)
1. Create a GitHub repository and upload app.py, requirements.txt and the data folder.
2. Go to share.streamlit.io, sign in with GitHub, click "Create app".
3. Choose the repository, set the main file to app.py, click Deploy.
